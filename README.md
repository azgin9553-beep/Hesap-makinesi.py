# 🧮 Python Hesap Makinesi

Basit, hızlı ve kullanımı kolay bir Python hesap makinesi.

## 🚀 Özellikler

- ➕ Toplama
- ➖ Çıkarma
- ✖️ Çarpma
- ➗ Bölme
- 🔢 Üs Alma
- √ Karekök
- 📊 Mod Alma
- ❌ 0'a bölme hatasını kontrol eder.
- 🔄 Sürekli çalışan menü sistemi.

## 📦 Gereksinimler

- Python 3.x

## ▶️ Kurulum

1. Depoyu indirin veya klonlayın.

```bash
git clone https://github.com/kullaniciadi/python-hesap-makinesi.git
```

2. Proje klasörüne girin.

```bash
cd python-hesap-makinesi
```

3. Programı çalıştırın.

```bash
python hesap_makinesi.py
```
